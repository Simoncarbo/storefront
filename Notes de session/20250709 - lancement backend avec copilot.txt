Implement a vote process where users send their idea, and one is randomly selected as an output.

Create a javascript class in vote_process.js for the frontend, a python class in vote_process.py for the backend. They should communicate through websockets, for which the logics should be specified in consumers.py and websocket_handlers.js.

In the frontend, a voting button with text "Envoyer vote" at the bottom of the page (under idea-inputs) enables the user to vote for the idea selected in ideas_manager.py (use getSelectedIdeaValue() function). Only one vote per participant is allowed. Clicking on the button thus freezes all the IdeaInputs, the radio buttons and the voting button. Once clicked, next to the button should appear a (dynamic) symbol to symbolize waiting and the message "En attente des autres participants". If the backend launches a countdown, show the countdown in red next to the button (and remove the message and symbol related to waiting if it is present).

In the backend, the ideas for which participants vote are gathered. Once 80% of the channel layer group members have sent their vote, launch a countdown of 20 seconds. The vote process ends when either 100% of the group members have sent their vote or the countdown is finished. Once the voting is finished, return a randomly selected idea as the result of the vote.
