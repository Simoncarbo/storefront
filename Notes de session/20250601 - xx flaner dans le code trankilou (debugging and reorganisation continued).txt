Quid d'ajouter ?version=2 au path de .js? Demande ChatGPT
The ?version=2 in the script tag is a query parameter appended to the URL of the JavaScript file. It serves a key role in cache busting.Browsers aggressively cache static assets like JavaScript, CSS, and images. If you update your JS file but keep the URL the same, users may continue to load the old, cached version and never see your changes.

Appending a query string like ?version=2 forces the browser to fetch a fresh version from the server because the URL has changed, even though the base file is the same.
